# DUCKScripts

Automated multi-client Ultra boss and army scripts for AQW on Skua.

## Installation

Clone or copy the `DUCKScripts` folder directly into your Skua `Scripts` directory:

```bash
cd "%appdata%\Skua\Scripts"
git clone https://github.com/faradayj/DUCKScripts.git
```

*(Or download the repository ZIP from GitHub and extract the `DUCKScripts` folder into your `Skua/Scripts/` directory)*.

## How to Run

1. Open **Skua** and log in to your accounts.
2. Open the **Script Manager** in Skua (`Scripts` -> `Load Script` or browse files).
3. Navigate to `DUCKScripts/UltrasDUCK/`:
   - **All Ultras**: Select `0AllUltrasDUCK.cs` (or `0AllUltras7DUCK.cs` for 7-player bosses).
   - **Specific Boss**: Select the individual script (e.g. `UltraDageDUCK.cs`, `UltraSpeakerDUCK.cs`, or inside `Dailies/`).
4. Click **Run** on all accounts. The bots will automatically synchronize, assign classes, and fight.
