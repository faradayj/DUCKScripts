1. EXECUTIVE SUMMARY: WHY ULTRA DRAKATH DUCK WAS DYING & FAILING
----------------------------------------------------------------------------------------------------
An in-depth code audit of UltraDrakathDUCK.cs compared to UltraDrakath_LW.cs revealed 3 major bugs
that caused 100% of the combat failures, missed taunts, and party wipes:

1. HARDCODED PLAYER NUMBER TAUNT ASSIGNMENT IN A DYNAMIC SOLVER
   - In UltraDrakathDUCK.cs, taunting was written as:
       isTaunter = Duck.IsArmyPlayer(2) || Duck.IsArmyPlayer(3);
       if (Duck.IsArmyPlayer(2)) return StoneCrusherTauntThresholds;
       if (Duck.IsArmyPlayer(3)) return ArchPaladinTauntThresholds;
   - In the DUCK dynamic framework, players are sorted ALPHABETICALLY by username, and classes
     are assigned based on account inventory/bank solving!
   - Result: If Player 2 was assigned Lord of Order, and Player 3 was assigned Chaos Slayer:
     * Lord of Order and Chaos Slayer equipped Scroll of Enrage and tried to taunt!
     * The actual StoneCrusher and ArchPaladin NEVER taunted and NEVER prepared Scroll of Enrage!
     * Drakath's 2M milestone nukes hit unmitigated, instantly wiping the party.

2. MISSING DEFENSIVE ENHANCEMENTS (VAINGLORY VS LAMENT & PENITENCE)
   - In UltraDrakath_LW.cs, explicit defensive cape overrides are enforced before combat:
     * `Vainglory` is strictly banned on Drakath because it reduces incoming healing by 50%.
       Any class with Vainglory is swapped to `Lament`.
     * `ArchPaladin` and `DPS` (Chaos Slayer / VDK / LR) are forced onto `Penitence` for +25%
       Damage Reduction.
   - In UltraDrakathDUCK.cs, `preset` was used raw without applying these Drakath-specific overrides.
     As a result, Chaos Slayer and AP retained Vainglory, received half heals, and died immediately
     to Drakath's incoming auto-attacks and nukes.

3. TAUNTER POTION OVERWRITE & PREPARATION
   - In UltraDrakath_LW.cs:
       if (isTaunter) preset.CombatPotion = null;
     This ensures Slot 5 is 100% reserved for `Scroll of Enrage` and prevents the skill engine
     from attempting to cast Felicitous Philtre or Potent Honor Potion over the taunt scroll.
   - In UltraDrakathDUCK.cs, taunters were incorrectly identified and potions were not suppressed.

====================================================================================================
2. DETAILED TAUNT MECHANICS & THRESHOLD CALIBRATION
====================================================================================================
Drakath executes catastrophic transition nukes every 2,000,000 HP lost.
The two taunters must alternate soaking the blasts:

StoneCrusher (Taunter 1):
  - Taunts at: 16,500,000 HP | 12,500,000 HP | 6,500,000 HP
ArchPaladin (Taunter 2):
  - Taunts at: 18,500,000 HP | 14,500,000 HP | 8,500,000 HP | 4,500,000 HP

Correct Implementation in DUCK:
```csharp
bool isStoneCrusher = string.Equals(preset.ClassName, "StoneCrusher", StringComparison.OrdinalIgnoreCase);
bool isArchPaladin = string.Equals(preset.ClassName, "ArchPaladin", StringComparison.OrdinalIgnoreCase);
isTaunter = isStoneCrusher || isArchPaladin;

private int[] GetTauntThresholds()
{
    if (isStoneCrusher)
        return AdjustedStoneCrusherTauntThresholds;

    if (isArchPaladin)
        return AdjustedArchPaladinTauntThresholds;

    return Array.Empty<int>();
}
```

====================================================================================================
3. CORRECTED DEFENSIVE ENHANCEMENT MATRIX
====================================================================================================
When `preset` is assigned in `UltraDrakathDUCK.cs`, the following modifications must be applied:

```csharp
// 1. ArchPaladin & DPS need Penitence for +25% Damage Reduction
if (isArchPaladin || string.Equals(preset.ClassName, "Chaos Slayer Berserker", StringComparison.OrdinalIgnoreCase) 
                 || string.Equals(preset.ClassName, "Verus DoomKnight", StringComparison.OrdinalIgnoreCase)
                 || string.Equals(preset.ClassName, "Legion Revenant", StringComparison.OrdinalIgnoreCase))
{
    preset.CapeEnhancement = CapeSpecial.Penitence;
}
// 2. Eliminate Vainglory across all other classes (-50% heal penalty causes death)
else if (preset.CapeEnhancement == CapeSpecial.Vainglory)
{
    preset.CapeEnhancement = CapeSpecial.Lament;
}

// 3. Taunters reserve Slot 5 strictly for Scroll of Enrage
if (isTaunter)
{
    preset.CombatPotion = null;
}
```
