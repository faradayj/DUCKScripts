4. PHASE 1: DUAL GRACE CRYSTALS (MAPID 2 & 3) — LINE-BY-LINE LOGIC
----------------------------------------------------------------------------------------------------
Function: `FightPhaseOne()` (lines 340-463)

4.1 Skill Engine Initialization:
  - Line 342: `LoneWolf.StartSkillEngine(...)`:
    * If `IsShamanPlayer()`: runs in `SkillEngineMode.Simple` with `Skills = { 1, 2 }`.
    * If `IsVerusDoomKnightComposition()`: runs in `Strict` mode, `blockedStrictSkill = 4`, `blockedStrictSkillTargetAura = "Safeguard"`.
    * Otherwise: runs `preset.SkillMode`.

4.2 Crystal Assignments (`GetAssignedCrystalMapId()` lines 1136-1139):
  - Player 1 (DPS) -> `CrystalAMapId` (MapID 2)
  - Player 2 (StoneCrusher) -> `CrystalAMapId` (MapID 2)
  - Player 3 (ArchPaladin) -> `CrystalBMapId` (MapID 3)
  - Player 4 (Lord of Order) -> `CrystalBMapId` (MapID 3)

4.3 Crystal Packet Detection & Taunt Ownership (`HandleCrystalDetections()` lines 939-968):
  - While `LoneWolf.HasPacketDetection(nextDetection)`:
    * `int cycle = nextDetection++;`
    * `OwnsTauntCycle(cycle)` (lines 1129-1134):
      - `openingOwner = LoneWolf.IsArmyPlayer(1) || LoneWolf.IsArmyPlayer(3);`
      - If `openingOwner`: owns Odd cycles (`cycle % 2 == 1`: cycles 1, 3, 5...)
      - If not: owns Even cycles (`cycle % 2 == 0`: cycles 2, 4, 6...)
    * Owning player calls `RequestGramielTaunt(crystalMapId)` (`LoneWolf.RequestTaunt(crystalMapId)`).
    * Sets `tauntTargetUntil = DateTimeOffset.Now.AddMilliseconds(1500)` on Player 2, Player 3, Player 4, Shaman, or VDK, locking target to crystal for 1.5s so the taunt completes.

4.4 Shaman Priority Skill 4 on Gramiel (`MaintainPhaseOneShamanSkillFour()` lines 970-1019):
  - If `IsShamanPlayer()` is true:
    * If `!openingSkillFourQueued`:
      Calls `LoneWolf.RequestTargetedPrioritySkill(4, GramielMapId, GramielMapId)` to fire Skill 4 on Gramiel (MapID 1) at fight opening, then returns target to Crystal A.
    * If `safeguardActive` is true and `!safeguardSkillFourQueued`:
      Calls `LoneWolf.RequestTargetedPrioritySkill(4, GramielMapId, GramielMapId)` to fire Skill 4 on Gramiel (MapID 1) during Safeguard shield.

4.5 Safeguard Aura Detection & Target Switching (`MaintainPhaseOneTarget()` lines 1020-1127):
  - `safeguardAttacker` determination (line 1049):
    * In `Default`: `LoneWolf.IsArmyPlayer(2) || LoneWolf.IsArmyPlayer(3)` (SC and AP).
    * In `Optimized` (Shaman): `true` (ALL 4 PLAYERS!).
  - When `Bot.Target.GetMonsterAura(GramielMapId).Contains("\"nam\":\"Safeguard\"")`:
    * If `currentSafeguard` is true:
      - If `DateTimeOffset.Now < tauntTargetUntil`: maintains assigned crystal.
      - Otherwise: calls `LoneWolf.MaintainTarget(GramielMapId)` -> switches attack to Gramiel (MapID 1) to break Safeguard.

4.6 Crystal Health Balancing Engine (lines 1083-1127):
  - `crystalBalancer` determination:
    * In `Optimized` (Shaman): `LoneWolf.IsArmyPlayer(1) || LoneWolf.IsArmyPlayer(2)` (Shaman & SC).
    * In `Default`: `LoneWolf.IsArmyPlayer(4)` (Lord of Order).
    * In `Test3 / Test4`: `LoneWolf.IsArmyPlayer(2) || LoneWolf.IsArmyPlayer(4)` (SC & LOO).
  - Balancing math:
    * `int difference = Math.Abs(crystalAHealth - crystalBHealth);`
    * If `!crystalBalancing && difference > 20`: sets `crystalBalancing = true`.
    * If `crystalBalancing`: targets `crystalAHealth >= crystalBHealth ? CrystalAMapId : CrystalBMapId` (attacks the crystal with MORE HP).
    * When `difference <= 2`: sets `crystalBalancing = false` and returns to assigned crystal.

4.7 Surviving Crystal Fallback:
  - If one crystal reaches <= 0 HP while the other is > 0 HP:
    * All players switch target to `survivingCrystal` (`emergencyTarget`).
  - When both `crystalAHealth <= 0 && crystalBHealth <= 0`: Phase 1 ends (`FinishPhaseOne(PhaseResult.Completed)`). Stops detector & skill engine.

5. PHASE 2: GRAMIEL NUKE CYCLE STATE MACHINE (3 CYCLES) — LINE-BY-LINE LOGIC
----------------------------------------------------------------------------------------------------
Function: `FightPhaseTwo()` (lines 465-799)

5.1 Skill Engine Initialization:
  - Line 471: `int[] normalSkills = GetPhaseTwoSkills(preset);`
    * For Player 1 in Default (LR): `{ 3, 4, 2, 1 }`
    * For Player 1 in Optimized (Shaman): `{ 1, 2 }`
    * For other players: `preset.Skills`
  - Starts skill engine with `preset.SkillMode` (for Shaman, `SkillEngineMode.Shaman`).

5.2 Grace Given Aura & Attack Detector Initialization (lines 543-564):
  - Loops until Gramiel has aura `GraceGivenAuraMarker` (`"nam\":\"Grace Given\""`).
  - Once detected, calls `StartPhaseTwoAttackDetector()` (lines 801-806):
    * Starts packet detector on `"ct"` with markers `GramielCasterMarker = "\"cInf\":\"m:1\""` and `AttackAnimationMarker = "\"animStr\":\"Attack"`.

5.3 The 7-Attack Sequence & Taunt Assignments (`GetPhaseTwoTauntAttack()` lines 918-930):
  - Player 1: `ownedAttack = 1`
  - Player 2: `ownedAttack = 3`
  - Player 3: `ownedAttack = 5`
  - Player 4: `ownedAttack = 7`

5.4 State 1: `PhaseTwoDetectorState.Attacks` (lines 567-685):
  - While `LoneWolf.HasPacketDetection(nextAttack)`:
    * `int attack = nextAttack++;`
    * **Attack 1 Slowdown on AP** (line 572):
      If `usePhaseTwoSlowdown && UsesDefaultCompositionBehavior() && Player 3 && attack == 1`:
      `LoneWolf.SetSkillEngineSkills(new[] { 2 }); rotationRestricted = true;` (AP casts skill 2 only).
    * **Attack 3 & Attack 7 on Shaman** (lines 584-606):
      - If `attack == 3 && usePhaseTwoSlowdown`:
        `LoneWolf.SetShamanSkillThreeEnabled(false);` (disables Skill 3 in ShamanSkillEngine).
      - If `attack == 7`:
        If `usePhaseTwoSlowdown`: `LoneWolf.SetShamanSkillThreeEnabled(true);` (re-enables Skill 3).
        `StartChargeTwoPacketDetector(); detectorState = PhaseTwoDetectorState.ChargeTwo; break;`
    * **Taunt Execution on `attack == ownedAttack`** (lines 645-683):
      - Calls `RequestGramielTaunt(GramielMapId)`.
      - If `IsOptimizedShaman()`: `continue;` (Shaman STAYS in Attacks state to monitor attacks 3..7).
      - If `Player 1` (LR) or `Player 3` (AP):
        If `Player 1 && usePhaseTwoSlowdown`: `LoneWolf.SetSkillEngineSkills(new[] { 3 }); rotationRestricted = true;`
        `StartLiberatorPacketDetector(); detectorState = PhaseTwoDetectorState.Liberator; break;`
      - Else (`Player 2` SC or `Player 4` LOO):
        `StartChargeTwoPacketDetector(); detectorState = PhaseTwoDetectorState.ChargeTwo; break;`

5.5 State 2: `PhaseTwoDetectorState.Liberator` (lines 687-739):
  - Listens on `"ct"` for `LiberatorMarker = "Liberator"`.
  - When detected:
    * Restores normal skills: `LoneWolf.SetSkillEngineSkills(normalSkills); rotationRestricted = false;`
    * Starts Charge2 detector: `StartChargeTwoPacketDetector(); detectorState = PhaseTwoDetectorState.ChargeTwo;`

5.6 State 3: `PhaseTwoDetectorState.ChargeTwo` (lines 741-751):
  - Listens on `"ct"` for `GramielCasterMarker` + `ChargeTwoAnimationMarker = "\"animStr\":\"Charge2\""`.
  - When detected:
    * Logs whether player has `Invulnerable` aura (`LogGramielProtection(nukeCycle)`).
    * Starts ChargeAttack2 detector: `StartChargeAttackTwoPacketDetector(); detectorState = PhaseTwoDetectorState.ChargeAttackTwo;`

5.7 State 4: `PhaseTwoDetectorState.ChargeAttackTwo` (lines 753-761):
  - Listens on `"ct"` for `GramielCasterMarker` + `ChargeAttackTwoAnimationMarker = "\"animStr\":\"ChargeAttack2\""`.
  - When detected:
    * Gramiel fires the nuke! Player takes 0 damage if protected by `Invulnerable`.
    * `LoneWolf.StopPacketDetector(); detectorState = PhaseTwoDetectorState.WaitingForInvulnerableEnd;`

5.8 State 5: `PhaseTwoDetectorState.WaitingForInvulnerableEnd` (lines 763-789):
  - While `Bot.Self.HasActiveAura("Invulnerable")`: waits.
  - When `Invulnerable` aura expires:
    * If `nukeCycle >= 3` (`GramielNukeCount = 3`):
      `detectorState = PhaseTwoDetectorState.Finished;` (all 3 nuke cycles completed).
    * Else:
      `nukeCycle++; nextAttack = 1;`
      Restores `normalSkills`, arms `StartPhaseTwoAttackDetector()`, and sets `detectorState = PhaseTwoDetectorState.Attacks;`

5.9 State 6: `PhaseTwoDetectorState.Finished` (lines 791-793):
  - Gramiel has no more nukes. Full skills DPS Gramiel until `gramielHealth <= 0`.
  - Returns `FinishPhaseTwo(PhaseResult.Completed)`.

7. ERROR RECOVERY, DEATH HANDLING, RESETS, AND QUEST COMPLETION
----------------------------------------------------------------------------------------------------
1. Death Recovery:
   - Phase 1 Death: Waits for alive, re-jumps to `r2, Down`, advances `nextDetection` through missed crystal charge packets via `AdvanceDetections()`.
   - Phase 2 Death: Waits for alive, re-jumps to `r2, Down`, resumes state machine from current `detectorState`.
2. Fight Reset (`HandleFightReset` lines 1154-1184):
   - Triggered if `LoneWolf.ShouldResetFight(fightAttempt)` is true.
   - Stops packet detector & skill engine.
   - Cancels target.
   - Jumps to `Enter, Spawn`.
   - Syncs all 4 players on `FIGHT_RESET_{fightAttempt}_SAFE`.
3. Max Attempts:
   - Allows up to 3 attempts (`MaxFightAttempts = 3`). If all 3 fail, stops army with `ATTEMPTS_EXHAUSTED`.
4. Quest Completion:
   - Once Gramiel reaches 0 HP, jumps to `Enter, Spawn`.
   - Calls `LoneWolf.CompleteUltraQuest(10301)`.
   - Syncs on `FINISH` and stops army.
