1. BOSS OVERVIEW & CORE THREAT MECHANICS
====================================================================================================
Champion Drakath is a 20,000,000 HP weekly ultra boss with lethal threshold damage mechanics:
1. Catastrophic Phase Transitions: Every 2,000,000 HP lost, Drakath charges a catastrophic nuke
   that deals extreme true damage to the party if not mitigated by a designated tank.
2. Drakath Enrage: At lower HP thresholds (sub-10M HP and sub-2M HP), Drakath's outgoing damage,
   crit chance, and haste ramp up significantly.
3. Survivability Requirement: To defeat Drakath without wiping, the army must rotate Scroll of Enrage
   taunts at exact HP milestones, ensuring that ArchPaladin and StoneCrusher alternate soaking
   the transition blasts with maximum damage resistance buffs active.

====================================================================================================
2. THE INTERLEAVED THRESHOLD TAUNT ARCHITECTURE
====================================================================================================
Unlike time-based taunt bosses (which taunt every 5-10 seconds), Champion Drakath in UltrasLW uses
a deterministic Health-Threshold Interleaved Array System.

Two dedicated taunters split the entire 20M HP health bar into ~2M HP intervals:
- Player 3 (ArchPaladin): Handles odd milestone thresholds (18.5M, 14.5M, 8.5M, 4.5M).
- Player 2 (StoneCrusher): Handles even milestone thresholds (16.5M, 12.5M, 6.5M).

Threshold Arrays in UltraDrakath_LW.cs:
----------------------------------------------------------------------------------------------------
Standard Thresholds (Default, Reliable, Optimized, Test):
  - ArchPaladin:    [ 18,500,000 | 14,500,000 | 8,200,000 | 4,200,000 ]
  - StoneCrusher:   [ 16,500,000 | 12,500,000 | 6,200,000 ]

Adjusted Thresholds (Stable [King's Echo] & Pay2Win [Guardian]):
  - ArchPaladin:    [ 18,500,000 | 14,500,000 | 8,500,000 | 4,500,000 ]
  - StoneCrusher:   [ 16,500,000 | 12,500,000 | 6,500,000 ]

Why thresholds are adjusted for King's Echo & Guardian:
- KE and Guardian have exceptionally high burst DPS and rapid buff scaling.
- The threshold triggers are slightly elevated (e.g. 8.5M instead of 8.2M, 6.5M instead of 6.2M)
  to ensure the taunt is landed *before* Drakath's HP gets melted past the nuke milestone!

4. COMBAT LOOP & THRESHOLD TRIGGER CODE
====================================================================================================
In UltraDrakath_LW.cs, the Fight method executes the threshold check on every poll tick (150ms):

```csharp
private FightResult Fight(ClassPreset preset, int fightAttempt)
{
    int[] tauntThresholds = GetTauntThresholds();
    int tauntIndex = 0;

    LoneWolf.StartSkillEngine(
        preset.Skills,
        playerAlias,
        isTaunter,
        LogPrefix,
        preset.SkillMode,
        maintainedPotion: !isTaunter && GetSetupOption<bool>("UsePotions") ? preset.CombatPotion : null
    );

    while (!Bot.ShouldExit)
    {
        if (!LoneWolf.IsMonsterAlive(BossMapId))
            break;

        if (LoneWolf.ShouldResetFight(fightAttempt))
        {
            LoneWolf.StopSkillEngine();
            return FightResult.Reset;
        }

        // Death Recovery
        if (!Bot.Player.Alive)
        {
            // Wait for respawn, jump back to r2, Left
            ...
            continue;
        }

        int bossHealth = LoneWolf.GetMonsterHP(BossMapId);
        LoneWolf.MaintainTarget(BossMapId);

        // THRESHOLD EVALUATION:
        if (
            tauntIndex < tauntThresholds.Length
            && bossHealth > 0
            && bossHealth <= tauntThresholds[tauntIndex]
        )
        {
            int threshold = tauntThresholds[tauntIndex];
            if (armyComposition == ArmyComposition.Test)
                LoneWolf.RequestAbsolutePriorityTaunt(BossMapId);
            else
                LoneWolf.RequestTaunt(BossMapId);

            tauntIndex++;
            Core.Logger($"{LogPrefix} {playerAlias} requested taunt at {threshold} HP.");
        }

        Bot.Sleep(FightPollDelay);
    }

    LoneWolf.StopSkillEngine();
    return !LoneWolf.IsMonsterAlive(BossMapId) ? FightResult.Defeated : FightResult.Stopped;
}
```

Key Details:
1. `tauntIndex` starts at 0 and increments strictly after each threshold is crossed.
2. `LoneWolf.RequestTaunt(BossMapId)` signals the skill engine to pause the primary rotation,
   equip `Scroll of Enrage`, cast Skill 5 on Drakath, and resume the class rotation.
3. Non-taunters (`Player 1` and `Player 4`) have an empty threshold array (`Array.Empty<int>()`),
   allowing them to focus 100% on DPS and party buffing.

5. BREAKDOWN OF ALL 6 ARMY COMPOSITIONS
====================================================================================================
`UltraDrakath_LW.cs` supports 6 distinct party compositions tailored for different player rosters:

1. Default Composition (LR / SC / AP / LOO)
   - Player 1: Legion Revenant (DPS, Decay, Crit/Damage Buffs)
   - Player 2: StoneCrusher (Buffer, Taunter: 16.5M, 12.5M, 6.2M)
   - Player 3: ArchPaladin (Defense, Debuffer, Taunter: 18.5M, 14.5M, 8.2M, 4.2M)
   - Player 4: Lord of Order (Haste, All-Stats, Burst Healing)
   - Profile: Safe, reliable, accessible to all standard accounts.

2. Stable Composition (KE / SC / AP / LOO)
   - Player 1: King's Echo (High sustained single-target burst)
   - Player 2: StoneCrusher (Taunter: Adjusted thresholds)
   - Player 3: ArchPaladin (Taunter: Adjusted thresholds)
   - Player 4: Lord of Order
   - Profile: Faster kill times while maintaining total stability.

3. Reliable Composition (VDK / SC / AP / LOO)
   - Player 1: Verus DoomKnight (Heavy single-target defense debuffs & true damage)
   - Player 2: StoneCrusher
   - Player 3: ArchPaladin
   - Player 4: Lord of Order
   - Profile: Extremely fast shredding of Drakath's defenses.

4. Optimized Composition (Chaos Slayer / SC / AP / LOO)
   - Player 1: Chaos Slayer (Courageous/Pandotheism debuffs for maximum DPS amplification)
   - Player 2: StoneCrusher
   - Player 3: ArchPaladin
   - Player 4: Lord of Order
   - Profile: High-risk, high-reward speed-run composition.

5. Pay2Win Composition (Guardian / AP / LR / LOO)
   - Player 1: Guardian (Massive party damage reduction, shields, and burst DPS)
   - Player 2: ArchPaladin (Swapped to Slot 2)
   - Player 3: Legion Revenant (Swapped to Slot 3)
   - Player 4: Lord of Order
   - Special Enhancements:
     - Player 2 (AP): Weapon = Praxis, Cape = Lament
     - Player 3 (LR): Helm = Hearty, Cape = Lament
     - Player 4 (LOO): Maintained Combat Potion = Felicitous Philtre
   - Profile: Ultra-fast carry composition for high-end accounts.

6. Test Composition (LR / SC / AP / LOO with Absolute Priority Taunts)
   - Uses `RequestAbsolutePriorityTaunt` to instantly interrupt skill animations for taunting.

6. DEFENSIVE ENHANCEMENTS & POTION LOADOUTS
====================================================================================================
Because Drakath hits with massive true damage during threshold nukes, gear loadouts are specifically
hardened in `UltraDrakath_LW.cs`:

1. Cape Modifications:
   - `CapeSpecial.Penitence`: Mandatory on ArchPaladin (Player 3) and Player 1 (LR/VDK) to provide
     +25% Damage Reduction.
   - `CapeSpecial.Vainglory` is strictly replaced with `CapeSpecial.Lament` (Vainglory reduces incoming
     healing by 50%, which causes players to die to follow-up threshold hits).

2. Helm Modifications:
   - In Pay2Win / Guardian setups: `HelmSpecial.Hearty` is equipped on Player 3 to increase base Max HP.

3. Potions:
   - All players prepare Tonic (Body Tonic / Sage Tonic), Elixir (Potent Battle / Malevolent), and
     Combat Potion (Felicitous Philtre).
   - Taunters (Player 2 and Player 3) omit the combat potion to keep Slot 5 exclusively dedicated
     to `Scroll of Enrage`.

7. WIPE RECOVERY, SAFE ROOM TRANSITIONS & LOCKSTEP SYNC
====================================================================================================
1. Synchronized Setup:
   - All 4 accounts join `championdrakath-<room>`, `Enter`, `Spawn`.
   - Players execute `PrepareSafeRoom` (potions, `Scroll of Enrage`, and `GenericPrebuff`).
   - Sync on `FIGHT_READY`.
2. Room Jump:
   - All 4 accounts jump simultaneously to `r2`, `Left` and sync on `START_FIGHT`.
3. Wipe Recovery (`HandleFightReset`):
   - If any player dies and `ShouldResetFight` triggers (or wipe occurs):
     - Skill engine is halted immediately (`StopSkillEngine`).
     - Combat target is cancelled (`CancelTarget`).
     - Players wait for respawn (500ms poll).
     - Players jump back to `Enter`, `Spawn` and synchronize on `FIGHT_RESET_<attempt>_SAFE`.
     - Potions are re-applied and the army attempts the fight again up to `MaxFightAttempts = 3`.
4. Turn-In & Finish:
   - When Drakath dies: army jumps to `Enter`, `Spawn`, calls `LoneWolf.CompleteUltraQuest(8300)`,
     and synchronizes on `Sync("FINISH")`.
